OCR 识别服务

内置 OCR 服务，为其他插件提供统一的文字识别能力

▾

调用示例
// 其他插件可以通过 host 调用 OCR 服务（默认优先 RapidOCR）

const result = await host.ocr(image, {
  engine: 'rapidocr', // 或 'system' / 'tesseract'
  lang: 'chi_sim'
})
console.log(result.text, result.confidence)

// 或本窗口 API
await window.ocrService.recognize(image, { engine: 'rapidocr' })
